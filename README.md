# Clasificador de Textos por Objetivos de Desarrollo Sostenible 
Esta es una aplicación interactiva que permite clasificar los textos de acuerdo a las **17 objetivos de Desarrollo Sotenible (ODS)**, utilizando Machine Learning no Supervisado y el algoritmo de RandomForest.
